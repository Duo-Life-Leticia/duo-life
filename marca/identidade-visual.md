# Identidade visual da Duo Life

Definida pelo Alessandro em 31/10/2026, a partir da logo. Vale para tudo o que for feito
(painel, protótipos, telas, documentos) até a Letícia e o Diogo aprovarem.

## Logo

- `logo-duo-life.jpg`: original, quadrada (sereia, sol, "Duo Life" e siri em dourado sobre azul-marinho)
- `logo-duo-life-horizontal.jpg`: recorte horizontal, sem a sobra de fundo, para cabeçalhos

## Cores

| Uso | Cor |
|---|---|
| Fundo principal (azul-marinho da logo) | `#021A4B` |
| Fundo de cartões e caixas | `#0A2560` |
| Linhas e bordas | `#1F3D7A` |
| Dourado principal (botões, títulos) | `#E8B04A` |
| Dourado claro (destaques) | `#F7E082` |
| Dourado escuro (sombra, botão pressionado) | `#C98E22` |
| Texto sobre o azul | `#F4ECD8` |
| Texto secundário | `#B8C2DC` |
| Texto sobre botão dourado | `#021A4B` |

- Botões: fundo dourado `#E8B04A` com texto azul-marinho `#021A4B`.
- Fundo: sempre o azul-marinho, com claro ou escuro no celular.

## Letras

- Títulos: Cinzel (serifa clássica, parecida com a da logo)
- Texto: Nunito Sans
